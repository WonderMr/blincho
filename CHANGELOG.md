# Changelog

Release notes are curated here before a version tag is pushed. The website keeps published GitHub release history and links to the full notes for each version.

## [1.3.3]

- Launch the Blincho website with 15 languages, automatic language detection, light/dark/system themes, downloads and release history.
- Include the compact desktop interface, localized settings and brief activity notifications.
- Publish native macOS, Windows and Linux packages for Intel/AMD and ARM computers through one version tag.
- Include SHA-256 checksums with every release and update website downloads only after all package builds succeed.
- Keep desktop downloads explicitly labelled as unsigned beta builds with their signing and platform-validation limitations stated.

## Earlier development versions

Earlier versions were developed before this public release process. Their local validation records are not a public release archive. Future published releases remain available in the [GitHub release history](https://github.com/WonderMr/blincho/releases).

Release preparation note: the v1.3.2 build stopped before publication because the Linux AppImage architecture filename differed. Version 1.3.3 normalizes the package filename. No public v1.3.2 release files were published.
